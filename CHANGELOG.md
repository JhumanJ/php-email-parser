# Changelog

## 0.1.0 — 2026-10-01

Initial public release:

- One immutable PHP API for EML and Outlook MSG email extraction, independent of Laravel.
- Addresses, dates, UTF-8 text/HTML, attachments, inline IDs and embedded emails.
- Original bounded CFB v3/v4 and LZFu/MELA RTF readers with text and encapsulated HTML extraction.
- EML archive export, explicit warnings/strict mode and configurable resource limits.
- PHPUnit regression suite, fixture provenance, PHPStan and CI on PHP 8.2–8.5.
